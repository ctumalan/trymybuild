# Homepage and app feedback release

- Clear, consistent header/footer slogan and stable Explore/Share navigation.
- Try-first cards with violet actions, secondary Save/Share, collapsible comments, and supplied access notes.
- Compact app details with consolidated creator information, related-app back navigation, and restrained motion with reduced-motion support.
- Return feedback from both card and detail actions: no prompt below 7 seconds, private checkbox responses from 7 to under 15 seconds, written feedback at 15 seconds or more. Timing reflects browser departure/return, not verified app usage.
- Creators can read private checkbox responses on their app dashboard. Existing public comment moderation remains unchanged.
- Development-only catalog fallback reads the public production catalog when local database configuration is missing.

## Release checks

- 210 automated tests pass; type check and production build pass.
- Migration 024 applied to the production database before deployment.
- Database verification: row-level security enabled, direct anonymous/authenticated reads and writes denied, server access available; all 11 published apps have owners.
- No sample listing or public review submitted. FinalPrompt.ai will be tested by the user after publication.

## Limitations

- Returning to a browser tab does not prove the visitor used an app. Feedback is optional and each prompt type appears once per app per page visit.
- Real newcomer comprehension and the complete FinalPrompt.ai listing journey remain user acceptance tests.
