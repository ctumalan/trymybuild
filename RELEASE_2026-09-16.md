# TryMyBuild journey improvements — September 16, 2026

Guest Save and composed feedback now explain the account requirement in a modal. The pending save, app, creator profile, selected profile tab, browsing filters and scroll position are retained through sign-in. Feedback drafts stay local until the member explicitly submits.

Invitations have readable font-independent PNG artwork, a compact delivery selector, browser Gmail/Yahoo/Outlook drafts, optional image/PDF controls, and linked images in copied HTML email. Standalone PNG files cannot contain active hyperlinks. Browser compose links do not automatically insert files or send email.

Public creator profiles consolidate projects, activity, about and messaging into one card. App details open in the right drawer over the profile. Location is optional, self-entered and public only when explicitly selected. Creator type and verification stay separate; Studio remains a founder-confirmed company without an earned creator badge.

Feedback and saved-feedback navigation is retired. Conversations and project comments appear in Messages; saves and comments trigger private owner notifications respecting preferences. Saved apps remain accessible. Overview highlights five approved qualifying reviews across three other creators plus confirmation of published app ownership. Historical identity flags alone do not display an earned badge. Companies remain welcome without payment or participation restrictions.

The existing quote pop-up locations and timing are preserved. Returning after more than 120 seconds opens detailed feedback with clickable choices and one comment field. Video remains in authenticated project settings, outside the initial journey. Visible founder references use Christian Tumalan. Footer slogan, About how-it-works and repeated no-sign-in notices were removed. Journey progress and preview styling were corrected.

## Database deployment

Migration `database/025_creator_journey_polish.sql` applied transactionally to the existing Supabase project. Before applying, the prior verification request function and profile rows were copied into private schema `release_backup_20260916_025`. Public/browser/service-role access to the backup was revoked and backup tables have RLS enabled. The migration adds profile type/location fields, earned badge progress and guards, and transactional save/comment notifications; it does not delete user data or automatically award badges.
